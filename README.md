# OCC_CGAL_Test

这是一个基于 **OpenCASCADE (OCC)**、**CGAL** 和 **Clipper2** 的几何处理实验项目，主要用于 2D/3D 几何布尔运算、凸包计算以及特征提取。

## 核心功能

- **模型读取与离散化**：使用 OpenCASCADE 读取 STEP 格式模型，并将其离散化为三角网格。
- **凸包计算**：集成 CGAL 库，支持从离散点云生成 3D 凸包以及 2D 轮廓的凸包修复。
- **多层型腔拆解**：针对复杂模型，实现了基于 Z 轴的递归切割策略，能够自动识别并拆解多层开放型腔特征。
- **布尔运算优化**：集成 Clipper2 库处理 2D 轮廓，并针对嵌套路径进行了特殊优化（采用顺序扣除而非单一非零填充规则）。
- **几何验证**：支持将处理结果导出为 BREP 格式，方便在 CAD 软件中进行可视化验证。

## 技术栈

- **语言**：C++ 17
- **几何内核**：OpenCASCADE (OCC) 7.7.0
- **算法库**：CGAL 5.6.2, Boost 1.74.0
- **2D 布尔运算**：Clipper2

## 构建说明

项目使用 CMake 进行构建。请确保在 `CMakeLists.txt` 中正确配置了以下环境变量：

- `BOOST_ROOT`: Boost 库路径
- `CGAL_DIR`: CGAL 库路径
- `OCC_BASE_DIR`: OpenCASCADE 安装路径

### 编译步骤

```bash
mkdir build
cd build
cmake ..
cmake --build . --config Release
```

## 工程约定

- **顶点优先**：在面包含性判定中，优先使用基于顶点的几何逻辑而非形心，以确保对凹多边形或同心圆形状的准确处理。
- **递归拆解**：在处理开放型腔时，在最高中间平面进行切割，分析连通性后再决定是否继续递归，避免过度碎化。
- **高度过滤**：在过滤嵌套闭合型腔面时，使用几何高度阈值而非仅依赖面 ID。
